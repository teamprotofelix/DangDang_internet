# 특허청구범위 기재불비 판단 규칙

## 관련 법령

### 특허법 제42조(특허출원) 제4항
제4항: 제2항제4호의 청구범위에는 보호받고자 하는 사항을 기재한 항(이하 "청구항"이라 한다)이 하나 이상 있어야 하며, 그 청구항은 다음 각 호에 해당하여야 한다.
1. 발명의 설명에 의하여 뒷받침될 것
2. 발명이 명확하고 간결하게 기재될 것

### 특허법 시행령 제5조(청구범위의 기재방법)
① 청구범위에는 보호받고자 하는 사항을 기재한 청구항이 하나 이상 있어야 한다.
② 청구항은 발명의 성질에 따라 적정한 수로 기재되어야 한다.
③ 하나의 청구항에 2 이상의 발명을 기재하거나, 하나의 청구항에 선택적인 기재를 하여서는 아니 된다.
④ 청구항은 발명의 구성을 기재하는 방식으로 기재하여야 한다. 다만, 발명의 성질상 발명의 구성을 기재하는 것이 적당하지 아니한 경우에는 발명을 한정하는 방법으로 기재할 수 있다.
⑤ 삭제
⑥ 청구항은 인용되는 청구항의 번호를 기재하여 인용관계를 명확히 하여야 한다.
⑦ 청구항은 인용되는 청구항의 모든 구성요소를 포함하여야 한다.
⑧ 2 이상의 청구항을 인용하는 청구항은 인용되는 청구항의 번호를 택일적으로 기재하여야 한다.

## 기재불비 판단 세부 기준

### 1. 명확성 요건 위반 판단 기준
1.1 용어의 불명확
- 청구항에 사용된 용어가 기술적으로 명확히 정의되지 않은 경우
- 상대적인 표현(예: "약", "대략", "실질적으로", "대체로" 등)이 기술적 한정 없이 사용된 경우
- 용어 자체가 모순되거나 비논리적인 경우

1.2 범위의 불명확
- 청구항의 보호범위가 명확히 특정되지 않은 경우
- 바람직한 실시형태만으로 기재되어 범위가 불명확한 경우
- 발명의 구성요소 간 관계가 불명확한 경우

1.3 표현의 불명확
- 청구항의 기재가 모순되거나 모호한 경우
- 부정적 표현으로만 기재되어 발명을 명확히 특정할 수 없는 경우
- 결과나 기능만으로 기재되어 구성이 특정되지 않은 경우

### 2. 뒷받침 요건 위반 판단 기준
2.1 청구범위가 발명의 설명에 의해 뒷받침되지 않는 경우
- 청구항에 기재된 사항이 발명의 설명에 전혀 기재되어 있지 않은 경우
- 청구항의 범위가 발명의 설명에 기재된 범위를 과도하게 확장한 경우

2.2 발명의 설명에 기재되어 있으나 청구항이 지나치게 넓은 경우
- 발명의 설명에는 특정 실시예만 기재되어 있는데 청구항은 그 이상으로 넓은 경우
- 실시예의 기재만으로는 청구항 전체를 뒷받침할 수 없는 경우

### 3. 기재방법 위반 판단 기준 (시행령 제5조)
3.1 제2항 위반: 청구항 수가 발명의 성질에 비해 과도하게 많거나 적은 경우
3.2 제3항 위반: 하나의 청구항에 2 이상의 발명이 기재된 경우
3.3 제3항 위반: 하나의 청구항에 선택적 기재가 있는 경우
3.4 제4항 위반: 발명의 구성을 기재하지 않고 작용·효과·기능만 기재한 경우
3.5 제6항 위반: 청구항의 인용관계가 불명확한 경우
3.6 제7항 위반: 종속항이 인용되는 청구항의 모든 구성요소를 포함하지 않은 경우
3.7 제8항 위반: 다중종속항이 택일적으로 기재되지 않은 경우

### 4. 간결성 요건 위반 판단 기준
- 청구항에 불필요한 기재가 포함되어 간결하지 않은 경우
- 동일한 내용이 중복되어 기재된 경우
- 발명의 구성과 무관한 기재가 포함된 경우

## 판단 시 유의사항
1. 각 위반 사항은 독립적으로 판단하며, 하나의 청구항에 여러 위반 사항이 있을 수 있음
2. 판단 결과에는 반드시 위반된 법조항을 명시할 것
3. 위반 내용을 구체적으로 설명하고, 출원인이 어떻게 보정해야 하는지 제시할 것
4. 거절이유는 청구항별로 구분하여 기재할 것
