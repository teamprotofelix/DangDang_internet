# DangDang_internet

브라우저에서 대화하고 함께 놀 수 있는 Chrome Manifest V3 반려 AI입니다. 사이드 패널과 플로팅 아바타, 로컬 대화 이력과 기억, 범용 코딩 프로젝트, KIPRIS PLUS 서류 다운로드를 지원합니다.

## 로컬 설치

### 설치용 ZIP

[GitHub Actions](https://github.com/teamprotofelix/DangDang_internet/actions/workflows/ci.yml)의 성공한 실행에서 **DangDang_internet_Chrome**을 내려받아 압축을 풉니다. Chrome 122 이상에서 `chrome://extensions`를 열고 **개발자 모드 → 압축해제된 확장 프로그램을 로드합니다**를 선택한 다음 `manifest.json`이 있는 폴더를 지정합니다. 설치용 ZIP은 Node.js와 npm 없이 사용할 수 있습니다.

### 소스 ZIP

GitHub **Code → Download ZIP**으로 받은 소스를 사용하려면 Node.js 24에서 `npm ci`와 `npm run package:extension`을 실행하고 `dist/DangDang_internet`을 로드합니다. 확장 프로그램의 **설정**에서 제공자와 API 키를 저장한 뒤 **연결 테스트**로 확인합니다.

## 대화와 코딩

- 대화창에서 **코드 요청**을 켜고 보냅니다. 드롭다운에서 **자동 감지**, 지원 언어 또는 **직접 입력**을 선택합니다. 이후 메시지도 같은 프로젝트 파일을 참고해 수정합니다. 코드 요청을 끄면 일반 대화로 돌아갑니다.
- **코딩** 탭의 **새 프로젝트**는 빈 상태에서 시작하고 **수정 요청**은 현재 파일을 사용합니다. **다시 생성**은 해당 요청의 입력·언어·원본 파일을 재사용합니다. 새 결과가 저장되면 현재 프로젝트가 바뀝니다. 프로젝트 파일 목록에서 선택한 소스는 복사하거나 저장할 수 있으며, 프로젝트 ZIP은 하위 폴더와 UTF-8 파일명을 보존합니다. 파일명과 확장자는 코딩 탭에서 편집할 수 있습니다.
- **프로젝트 초기화**는 확인 후 현재 요청과 생성 파일을 지웁니다. 대화 기록, 이전 대화 카드, 언어·모델 설정과 내려받은 파일은 보존됩니다.
- 모델이 반환한 소스는 텍스트로 표시합니다. 다운로드한 파일의 내용은 직접 확인한 뒤 별도 환경에서 사용하세요. 이전 HTML 세션은 `app.html`로 복원됩니다.
- **LG EXAONE (K-EXAONE 2.5)**는 `k-exaone_v2.5`를 사용합니다. 제공자마다 키가 분리되며 생성 한도에는 추론 토큰이 포함됩니다. 서비스 혼잡 시 429가 표시될 수 있습니다. [EXAONE API 문서](https://docs.exaone.ai/ko/docs/k-exaone-2.5)

## KIPRIS PLUS 서류 다운로드

1. **설정 → KIPRIS PLUS**에 본인의 키를 저장합니다. 상품 권한이 있는 출원번호로 연결을 검사합니다.
2. **KIPRIS** 탭에서 출원번호 13자리를 입력하고 **서류 조회**를 누릅니다. 행정처리 이력과 공식 상품의 원문 제공 상태가 표시됩니다. **최근 조회**에서 이전 출원번호를 선택할 수 있습니다.
3. 행의 **PDF 다운로드**를 누르면 공식 API 응답의 식별자를 대조하고 다운로드 주소를 새로 받습니다. HTTPS 호스트와 PDF 바이트 형식을 확인합니다. 공보와 정정공보는 설치본에 포함된 PDF.js로 첫 쪽의 식별 정보도 검사합니다. 정정공보 제목의 공개·등록 유형과 정정공고일, 일련번호를 확인할 수 없으면 저장이 보류됩니다. API에서 공보번호를 제공하지 않으면 첫 다운로드의 PDF에서 읽은 공보번호를 해당 행의 조회 메타데이터로 보관합니다. 같은 PDF 경로에서 알려진 임시 토큰만 바뀐 경우에도 이후 다운로드는 이 번호와 일치해야 합니다. 문서 선택자가 변경되면 서류 목록을 다시 조회해 주세요.
4. **전체 ZIP 다운로드**는 조회할 수 있는 PDF를 출원번호별 ZIP으로 저장합니다. 파일당 최대 20 MB, ZIP 원문 합계 최대 100 MB입니다. 일부 실패 시 성공한 파일과 실패 사유가 표시되며, 전부 실패하면 ZIP을 만들지 않습니다.
5. **이 출원 지우기** 또는 **검색 기록 전체 지우기**를 확인하면 해당 범위의 조회 정보와 이전 특허 진단에서 저장한 로컬 원문·보고서가 삭제됩니다. 업데이트 직후 기존 진단 자료는 보관되며, Chrome으로 이미 내려받은 파일과 API 설정은 지우기 대상에서 제외됩니다.

## 개인정보와 검증

- 기본 설정은 웹 콘텐츠 인식과 기억 메모의 모델 전송을 끕니다. 일반 대화 전송 시 입력과 대화 맥락은 선택한 모델에 전송됩니다.
- KIPRIS PLUS 키는 LLM 키와 별도 로컬 저장소에 보관합니다. 확장 저장소에는 조회 메타데이터만 기록합니다. KIPRIS 원문은 다운로드할 때 메모리에서 처리합니다.
- `npm ci && npm test`로 합성 자료 기반 테스트를 실행합니다. Chromium 통합 검증은 `npx playwright install chromium` 후 `DANGDANG_EXTENSION_DIR=dist/DangDang_internet npm run test:browser`로 실행합니다. 사용자의 실제 키나 문서는 테스트에 필요하지 않습니다.
